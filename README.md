# Antigravity Telegram Bot

Telegram-бот для удаленного мониторинга и управления Google Antigravity. Позволяет просматривать активные проекты, чаты, историю переписки, отправлять промпты и управлять процессом генерации кода из любого устройства через Telegram.

## Структура проекта

- `bot.py` — основной бот на `python-telegram-bot` (интерфейс, инлайн-кнопки, обработка сообщений)
- `bridge.py` — мост связи с Antigravity (LSP-протокол, поиск активных процессов, чтение истории)
- `watcher.py` — фоновый трекер ответов модели в реальном времени
- `run_bot.py` — запуск с валидацией окружения и проверкой прав доступа
- `log_config.py` — конфигурация логирования в файл и консоль
- `test_bot_bridge.py` — набор тестов для проверки связи с Antigravity
- `start_bot.bat` — скрипт быстрого запуска бота двойным кликом

## Быстрый запуск

1. Убедитесь, что в файле `.env` указан токен бота и ваш Telegram ID:
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   ALLOWED_TELEGRAM_USER_IDS=ваш_telegram_id
   ```
2. Запустите бота через `start_bot.bat` или командой:
   ```bash
   python run_bot.py
   ```
3. Откройте Telegram и напишите `/start` боту.
